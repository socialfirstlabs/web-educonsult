# Project Images

Place project-specific image assets here:
- `logo.svg` / `logo.png` — brand logo used in Navbar and Footer
- `og-image.jpg` — Open Graph image (1200×630) for social sharing metadata
- `hero-bg.jpg` — optional hero section background
- `favicon-*.png` — various favicon sizes (16, 32, 180, 192, 512px)

Reference these in code as `/images/logo.svg` (served from the `public/` root).
